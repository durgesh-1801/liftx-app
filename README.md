# LiftX 🚀

A competitive gym workout tracker that gamifies fitness with leaderboards, streaks, and performance analytics.

## 🔥 Features
- Workout logging (sets, reps, weight)
- Personal record (PR) tracking
- Weekly leaderboard (volume-based)
- Streak tracking
- Firebase authentication

## 🧱 Tech Stack
- React Native (Expo)
- Firebase (Auth + Firestore)
- Zustand / Context API

## 📱 Screens
- Login / Signup
- Dashboard
- Workout Logger
- Leaderboard
- Profile

## 🚀 How to Run
```bash
npm install
npx expo start
